# Emploi du temps d’Enzo

Application web installable (PWA), sans dépendances, adaptée au téléphone.

## Utilisation
- Couleurs par matière, vue du jour et de la semaine.
- Alternance calendaire : lundi 31 août 2026 = Q1 ; lundi 7 septembre 2026 = Q2.
- Horaires affichés à l’heure de la Guadeloupe.
- Installation depuis le navigateur, puis consultation hors connexion après mise en cache.
- Partage du lien de l’application.

## Publication sur GitHub Pages
Dans Settings > Pages, sélectionner « Deploy from a branch », puis « main », « / (root) » et Save.
L’adresse par défaut attendue après publication est : https://jmlobeau-dot.github.io/Emploi-du-temps-enzo/

## Limites et confidentialité
Ce planning a été retranscrit à partir de la photo fournie datée du 4 septembre 2026. Il n’est pas synchronisé avec le collège : absences, changements, jours fériés et vacances ne sont pas intégrés. L’alternance continue chaque semaine calendaire, y compris pendant les vacances ; vérifier la reprise avec le collège.

Le dépôt et le site GitHub Pages sont publics. Une adresse partagée et une directive noindex ne constituent pas un contrôle d’accès. Ne pas ajouter de documents privés, de coordonnées ou de secrets.

## Maintenance
Modifier index.html pour les cours. À chaque publication, modifier la version du cache dans sw.js. La prochaine ouverture en ligne permet de récupérer la nouvelle version ; hors connexion, la dernière version mémorisée est utilisée.
